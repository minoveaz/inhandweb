# INHAND — WEB BRAND KIT / v1.0

Kit de traspaso para equipo de desarrollo web. Dirección **B · Creativa**.

## Estructura
- `../logos/`: logotipo INHAND y letra A más recientes, junto con el isotipo IH original y sus variantes SVG/PNG. Esta carpeta es la referencia vigente de logos.
- `01_brand_assets/`: wordmarks **reconstruidos de referencia** (NO arte maestro aprobado).
- `02_design_tokens/`: paleta y tipografías en JSON y CSS.
- `03_web_components/`: página HTML ilustrativa (abrir con servidor local).
- `04_visual_references/`: referencias visuales seleccionadas y manifest.
- `05_documentation/`: pautas de uso, contenido y pendientes.

## Marca
**INHAND — MADE TO MEAN MORE.**

Propuesta: productos de diseño contemporáneo inspirados en la fe cristiana, pensados para expresar, compartir y celebrar aquello que realmente importa.

Posicionamiento: **Diseño protagonista. Fe claramente presente.**

## Nota de precisión sobre el logotipo
En `../logos/` se conserva el isotipo vectorial facilitado en el proyecto como **fuente de geometría**, junto con sus variantes recoloreadas. El SVG original utiliza `#002B8C`; las variantes web usan el azul de la paleta B `#2638A5`. **El wordmark reconstruido en SVG es una aproximación tipográfica de integración y no sustituye el logotipo maestro oficial**. Solicitar archivo maestro del logotipo INHAND con el detalle coral en la A antes de publicación.

## Imágenes
Las imágenes de producto son **conceptuales generadas por IA**; no son fotografías reales, renders CAD consistentes ni evidencia de productos comercializados. Evitar usarlas como prueba de disponibilidad, especificaciones finales o fabricación. Muchas incluyen texto rasterizado: revisar erratas antes de publicación. No recortar mosaicos para simular fotos individuales sin validar su calidad.

## Uso web
Usar textos HTML y CSS para títulos, fichas, categorías y botones; reservar las imágenes como apoyo visual. No publicar las slides técnicas completas como contenido accesible principal. Exportar imágenes optimizadas a WebP/AVIF según el proyecto y añadir texto alternativo.
